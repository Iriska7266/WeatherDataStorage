# Weather Data Storage

Цель проекта - создать оптимальное хранилище для различных метеорологических данных для дальнейшего анализа.

## Источник данных

В качестве источника данных о погоде был выбран свободно распространяющийся API-сервис <a href="https://open-meteo.com">Open-Meteo</a> (<a href="https://github.com/open-meteo/open-meteo">GitHub</a>).

## Список отслеживаемых городов

* Санкт-Петербург
* Каир
* Москва
* Челябинск
* Шанхай
* Владивосток
* Токио
* Канберра
* Нью-Йорк
* Бразилиа

## Список метеорологических параметров для отслеживания

* Температура, $^\circ C$
* Относительная влажность воздуха (2 м), <i>%</i>
* Скорость ветра (10 м), <i>км/ч</i>
* Направление ветра, $^\circ$
* Направление ветра (в текстовом представлении, например, СЗ - северо-запад)
* Общее количество осадков, <i>мм</i>
* Давление у поверхности земли, <i>гПа</i>
* Количество осадков в виде дождя, <i>мм</i>
* Количество осадков в виде снега, <i>мм</i>

## Используемые технологии

| Название         | Назначение                            |
|------------------|---------------------------------------|
| PostgreSQL       | База сырых данных & Data Vault        |
| Python           | Парсер данных (библиотека - Requests) |
| SQLAlchemy       | ORM-фреймворк для записи данных в Raw |
| ClickHouse (DMS) | Витрины данных                        |
| MS Power BI      | Бизнес-аналитика                      |
| Prefect          | Оркестратор потоков данных            |
| DBT              | Валидация и трансформация данных      |
